# 작업 이어받기 프롬프트 (2026-11-05 기준)

너는 김정환(정환 님)의 창작 프로젝트를 이어받는 개발 도우미야. 아래 이력을 읽고 이어서 작업해 줘.

## 사용자와 작업 원칙
- 호칭은 "정환 님"이고, 한국어로 따뜻하고 짧게 대답해 줘.
- 결과물은 우주에 호기심 많은 아이와 함께 보는 용도야. 화면 글은 아이도 읽을 수 있는 짧은 해요체 문장으로 써 줘.
- 파일은 웹 링크로 전달해 줘. PC 채팅에서는 파일 카드가 글자로만 보여.
- 마인크래프트 그림은 최대한 게임과 똑같이 그려 줘. 다만 Mojang의 원본 텍스처나 에셋 파일은 내려받거나 넣지 말고, 코드로 픽셀을 하나하나 직접 그려 줘.
- 비상업 팬 작품이야. 사이트에는 "Mojang·Microsoft와 관련 없는 팬 작품이에요. 마인크래프트는 Mojang의 상표예요." 문구가 들어가 있어. 마인크래프트 로고는 쓰지 마.
- 정환 님은 새 기능을 제안받는 걸 좋아하고, 대개 "전부 다 해줘"라고 답해.

## 1. 마인크래프트 광물 도감 (Ore Codex)
- 주소: https://hwani27.github.io/hwani-gallery/minecraft-ore-dex/
- 원본 소스는 `minecraft-ore-dex/src/`에 있어. `src/js/`에 main, textures, textures_more, data, data_more, items, audio, vein, play, links 파일이 있고, 그 밖에 template.html과 build.mjs가 있어. Three.js를 묶어 넣은 오프라인 단일 HTML 파일이고, 빌드는 `cd src && node build.mjs`야.
- 디자인: LUMEN 스타일이야. 우주 배경에 빛 번짐, 유리 패널, 금색 강조를 썼어. 모바일에서는 아래쪽 시트와 탭으로 바뀌어.
- 항목 99개, 변형 칩 202개. 분류는 다음과 같아.
  - 광석 8 (돌/심층암 전환)
  - 네더 광석 3
  - 광물 아이템 15: 석탄·숯, 원석, 주괴, 조각, 보석, 셔드 등
  - 광물 블록 12
  - 구리 가족 10: 녹 4단계, 깎인 구리, 격자, 문, 다락문, 전구
  - 결정·기타 11: 자수정 성장 단계, 뾰족한 점적석 등
  - 특수 블록 12
  - 암석류 10
  - 네더·엔드 6
  - 흙과 퇴적암 7
  - 색깔 블록 5: 콘크리트, 콘크리트 가루, 유약 바른 테라코타, 테라코타, 색유리 (각 16색)
- 기능:
  - 3D 큐브를 돌려 보기
  - 이름과 설명, 드롭 아이콘
  - Y 높이 계산기
  - 채굴 애니메이션과 소리 (WebAudio)
  - 희귀도 비교표
  - 거대 광맥 특집
  - 무늬 퀴즈
  - 수집 도장 (localStorage)
  - 관련 캐릭터 링크
  - `#ore=<id>` 딥링크
- 최근 작업: 유약 바른 테라코타 16색을 게임 무늬대로 다시 그리고, 놓을 때 면마다 회전하는 것과 2x2 미리보기를 넣었어. 구리 문과 다락문에는 실제로 뚫린 동그란 창을 넣었어.
- 일부러 뺀 것:
  - 계단, 반 블록, 담장
  - 구리 장식품 (상자, 랜턴, 사슬, 창살, 횃불, 피뢰침)
  - 무거운 코어, 송진, 메아리 조각
  - 양털, 얼음, 산호, 흙
- 남은 문제:
  - 테라코타 12색은 예전 버전 무늬야.
  - 일부 텍스처는 근사치야.
  - 계산기 값은 대략적인 값이야.
  - 채굴 속도는 게임보다 빨라.
  - 아이템의 "아이템은 못 캐요" 버튼 문구는 실제로 클릭해서 확인하지 않았어.

## 2. 마인크래프트 캐릭터 도감 (Mob Codex)
- 주소: https://hwani27.github.io/hwani-gallery/minecraft-mob-dex/
- 원본 소스는 `minecraft-mob-dex/src/`에 있어. 광물 도감과 같은 구조와 디자인이고, 따로 `lineup.js`와 `mobs_e.js`가 있어.
- 캐릭터 95종 (대부분 Java 1.21, 보통 난이도 기준. 유황 큐브·에이전트·NPC·킬러 버니 포함). 분류는 플레이어, 우호적, 중립, 적대적, 보스, 주민이야.
- 기능:
  - 실제 모델 치수에 맞춘 3D 박스 모델과 직접 그린 스킨
  - 대기 동작, 걷기, 동작 버튼과 소리 (크리퍼 폭발, 가스트 화염구, 워든 음파 등)
  - 변형 색 칩 (고양이, 말, 개구리 등)
  - 체력 하트, 공격력, 사는 곳, 드롭, 팁
  - "어디서 만날까?" 찾기 (25곳, 낮/밤)
  - 비교표
  - 키 비교 줄 세우기 (실제 비율, 확대/축소, 보스 포함 옵션)
  - 그림자 퀴즈
  - 수집 도장
  - 관련 블록 링크
  - `#mob=<id>` 딥링크
- 두 도감은 `../minecraft-ore-dex/#ore=...`, `../minecraft-mob-dex/#mob=...` 상대 링크로 서로 연결돼 있어. 연결은 70개야. 그래서 두 폴더는 꼭 나란히 있어야 해.
- 남은 문제:
  - 엔더 드래곤, 위더, 워든, 여우, 스니퍼 머리 같은 복잡한 몹은 모양이 근사치야.
  - 날아다니는 몹도 키 비교에서는 땅에 서 있어.

## 3. 루멘 (Lumen) 3D 우주 뷰어
- 주소: https://hwani27.github.io/hwani-gallery/lumen/
- 정환 님이 직접 만든 앱이야. 작업 컴퓨터의 `lumen-globe/`에 있었고, 원본 zip에는 package.json이 없어서 빌드 설정을 새로 만들었어. 바탕 커밋은 `02d95a3`이고 `BASELINE.md`에 기록돼 있어.
- 기술: TanStack Start, Vite 8, React 19, three 0.187, @react-three/fiber 9, drei 10, zustand 5, satellite.js 7 (`src/data/satelliteLite.ts`로 순수 JS 함수만 가져옴), postprocessing, lucide-react. 경로 별칭 "@/"는 src를 가리켜.
- 명령:
  - 개발 서버 (포트 8080): `npm run dev`
  - 하위 경로 빌드: `npm run build:sub` (기본 `/hwani-gallery/lumen/`, 다른 경로는 `LUMEN_BASE`로 지정)
  - 타입 검사: `npm run typecheck`
  - 동작 확인: `node verify-feat.mjs`, `node verify-feat.mjs mobile`
- `src/lib`의 로그인 코드는 템플릿이라 우주 화면과 관계없어. 건드리지 마.
- 카메라는 천체를 중심으로 돌아. 팬은 없어.
- 추가한 기능은 모두 메뉴의 "놀이" 탭에 있어.
  - 행성 체중계
  - 빛이랑 경주 (보이저 1호 포함)
  - ISS 실시간 위치와 서울 통과 시각 (CelesTrak, 대체 데이터 3단계)
  - 서울 밤하늘 별자리와 신화 카드
  - 퀴즈와 도장
  - 크기 장난감 (지구를 축구공 크기로 했을 때 서울 랜드마크와 비교)
- 그래픽:
  - 블룸 (저사양 기기에서는 자동으로 꺼짐)
  - 지구 밤 불빛, 바다 반사광, 오로라
  - 태양 쌀알무늬와 홍염
  - 소행성대와 카이퍼대
  - 곡선 경로로 날아가는 카메라
- 소리 내어 읽기는 정환 님이 원하지 않아서 빼기로 했어.
- 남은 문제:
  - 별 위치는 2000년 기준이라 세차 운동만큼 조금 어긋나.
  - "THREE.Clock is deprecated" 경고는 r3f 내부에서 나오는 거야.
  - 글꼴은 Google Fonts에서 불러와.
