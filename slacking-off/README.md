# 부장님 몰래 딴짓하기 · Slacking Off Before 6

18:00 칼퇴까지, 부장님 눈을 피해 **딴짓 게이지 100%**를 채우는 원터치 눈치 게임 프로토타입.
`slacking-off/` 안에서만 동작하는 정적 웹게임입니다(빌드·의존성 없음, 외부 요청 없음).

## 실행

```
# 아무 정적 서버나
python3 -m http.server 8000
# → http://localhost:8000/slacking-off/
```

`index.html`을 파일로 바로 열어도 동작합니다.

## 조작

| 행동 | 모바일 | PC |
| --- | --- | --- |
| 딴짓(게이지 UP) | 모니터 화면 연타 | 모니터 클릭 |
| 일하는 척(위장) | `[💼 일하는 척!]` 꾹 누르기 | 버튼 홀드 / `Space` 홀드 |
| 시작·다음 | 버튼 탭 | `Space` |

## 규칙

- **딴짓 게이지**가 100%가 되면 그날은 칼퇴. 18:00(제한 시간)까지 못 채우면 **야근**.
- 부장님이 다가오는 동안(경고 1.0~1.6초) `[일하는 척!]`을 눌러 **업무 척도 55%** 이상을 만들면 통과,
  딴짓 중이면 **즉시 발각**.
- 위장 중에는 게이지가 조금씩 식고, 위장만 오래 하면 시간이 다 되어 야근이 된다.

### 3일 생존기

| 날 | 테마 | 특징 |
| --- | --- | --- |
| 월요일 | 잼부장 순찰 | 기본. 경고 1.55초 |
| 수요일 | 잼대리 유혹 공작 | 🍗 치킨 유혹(게이지 +12, 1.5초 위장 불가), 지나간 척 돌아보는 **페인트 모션** |
| 금요일 | 부장님 + 사장님 더블 체크 | 경고 1.05초, 연속 점검, 일만 하면 차는 **의심도 → 기습 점검** |

딴짓 화면도 날마다 다릅니다: 미니 블록 점프 → 코인 차트 떡상 → 핫딜 쇼핑 담기.

## 구성

```
slacking-off/
  index.html          화면 마크업 (상단 사무실 뷰 · 중앙 모니터 · 게이지 · 위장 버튼)
  css/style.css       레이아웃/연출 (390×844 세로 한 화면, PC는 중앙 프레임)
  js/sfx.js           Web Audio 프로시저럴 효과음 (타자·콤보·발소리·발각·칼퇴) + 음소거
  js/characters.js    잼부장·잼사장·잼대리·잼인턴 대사 풀과 말풍선
  js/game.js          상태 머신(평온→경고→점검→통과/발각), 미니게임, 엑셀 위장, 결과 화면
```

- 캐릭터·말투·사내 유머 톤은 `kaltoe-boardgame/js/characters.js`·`story.js`의 잼 회사 세계관을
  이 게임용으로 각색해 재사용했습니다. 원본 폴더는 수정하지 않습니다.
- 디버그 훅: 콘솔에서 `__SLACK.state()`, `__SLACK.warn(1)`, `__SLACK.tap()`, `__SLACK.hold()` 등으로
  상태를 확인/재현할 수 있습니다(테스트·검수용).

## 검증

headless Chromium으로 390×844 / 1280×800에서 pageerror·콘솔 에러 0건,
게이지 상승 · 위장 전환 · 통과/발각/야근/클리어 · 3스테이지 진행을 확인했습니다.
