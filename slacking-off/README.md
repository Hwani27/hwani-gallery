# 부장님 몰래 딴짓하기 · Slacking Off 3D

18:00 칼퇴까지 부장님 눈을 피해 **딴짓 게이지 100%**를 채우는 **월~금 5일** 생존 눈치 게임.
2026-11 3D 복셀 업그레이드: 상단 사무실과 중앙 '딴짓 창'이 모두 Three.js 복셀 3D로 렌더링된다.

## 플레이
- 모니터(중앙 3D 미니게임)를 연타 → 딴짓 게이지 UP. 요일마다 다른 3D 딴짓:
  - 월요일 · 잼부장 순찰 — 복셀 잼인턴이 점프하며 코인·별 획득
  - 화요일 · 잼부장 커피 급복귀 — 사내 메신저 말풍선을 터뜨리기
  - 수요일 · 잼대리 유혹 공작 — 코인 차트에 코인탄을 사격
  - 목요일 · 잼사장 뒤에서 접근 — 숏폼 카드를 한 장씩 넘기기
  - 금요일 · 부장님+사장님 더블 체크 — 핫딜 선물 박스를 망치로 격파
- `[일하는 척!]`을 꾹(PC는 Space) → `Q4_매출보고서_최종_진짜최종.xlsx`로 위장, 업무 척도 게이지 상승
- 부장님 감시(경고) 중 위장+척도 55%↑ = 통과 / 딴짓 중 = 발각 / 18:00까지 100% 미달 = 야근

## 상사 패턴
- **페인트 모션(수)**: 지나간 척하다 돌아본다.
- **커피 타러 갔다 급복귀(화)**: 부장님이 탕비실로 나가 잠깐 딴짓 타이밍이 열린다. 그런데 옆문으로 급히 돌아오면 경고가 0.6초 남짓뿐이다.
- **뒤에서 소리 없이 접근(목)**: 스텔스 접근. 발소리·경고 배너·붉은 비네트·REC 표시가 **한 박자 늦게** 뜬다(경고 시간의 42%는 아무 신호도 없다). 늦게 알아채면 발각.
- **더블 체크 + 의심도(금)**: 경고가 1초 남짓이고, 일만 오래 하면 의심도가 차서 기습 점검이 날아온다.

## 🚨 3초 변명 찬스
- 스테이지당 1회, **첫 발각**은 바로 게임오버가 아니라 3.0초 변명 타임으로 넘어간다.
- 방금 찍힌 상사 3D 호통 컷 + 대사 + 카운트다운 바 + 변명 3개(정답 1 + 오답 2, 매번 섞임).
- 딴짓 모드(월 점프 / 화 메신저 / 수 차트 / 목 숏폼 / 금 쇼핑) × 상사(잼부장/잼사장)별 밈 변명 30세트.
- **정답**: 상사가 솔깃한 반응 컷(1.2초) → +50점, 1.5초 무적, 딴짓 게이지 그대로 복귀.
- **오답·시간 초과**: 시말서 확정 호통 컷 → 발각 결과 화면(선택한 변명·시간 초과 표시).
- 두 번째 발각부터는 변명 없이 바로 발각 게임오버.

## ② 직급 승진 & 사무실 장비 상점 (localStorage)
- 판이 끝날 때마다 점수에 비례한 **월급 루팡 코인(₩)**을 받는다(`점수/60 + 클리어 45 · 발각 10`, 최대 220).
- **직급**: `인턴 → 사원 → 대리 → 과장 → 차장 → 부장`. 누적 클리어 수와 누적 코인을 **둘 다** 넘겨야 승진한다.

  | 직급 | 클리어 | 누적 코인 |
  | --- | --- | --- |
  | 사원 | 1 | ₩80 |
  | 대리 | 4 | ₩320 |
  | 과장 | 8 | ₩760 |
  | 차장 | 12 | ₩1,300 |
  | 부장 | 17 | ₩1,900 |

- 현재 직급 배지는 **타이틀 상단**과 **결과 화면(발각·야근·칼퇴·엔딩)** 에 표시되고, 승진하면 결과 화면에 `🎉 승진!` 이 뜬다.
- **🛒 사무실 장비 상점** — 타이틀의 `[🛒 장비 상점]` 버튼으로 모달을 연다. 코인으로 사고, 사는 즉시 이번 판부터 적용된다.

  | 장비 | 효과 | Lv.1 / 2 / 3 가격 |
  | --- | --- | --- |
  | ⌨️ 기계식 키보드 | 위장 업무 척도 상승 +15%/Lv | 120 / 300 / 560 |
  | 🖥️ 듀얼 모니터 | 딴짓 게이지 상승량 +20%/Lv | 150 / 340 / 620 |
  | 🕶️ 눈치 안경 | 상사 접근 경고 여유 +0.18초/Lv | 110 / 260 / 480 |
  | ☕ 아메리카노 텀블러 | 위장 중 게이지 감소 -40%/Lv (최소 15%) | 90 / 220 / 420 |

- 진행 상황은 `localStorage['slackOff.progress.v1']` 에 저장된다(코인·누적 코인·클리어·최고점·장비 레벨).

## 3D 구성 (`js/`)
- `three.min.js` — 로컬 Three.js r128 (외부 CDN 없음)
- `textures.js` — Poly Haven CC0 실사 텍스처(512px WebP) 비동기 로더·적용기
- `voxel.js` — 복셀 박스·사람(머리/눈/안경/정장·넥타이/팔다리 피벗)·이름표·파편 빌더
- `scene3d.js` — `OfficeScene`(사무실·잼부장/잼사장/잼대리 걷기·감시·발각 줌인·스텔스 뒤접근) + `MiniScene`(점프·메신저·차트·숏폼·쇼핑 5종 3D 미니게임) + `Slack3D` 루프
- `shop.js` — ② 승진·코인·장비 상점·localStorage 저장
- `excuse.js` — 3초 변명 찬스: 모드·상사별 변명 풀, 3개 셔플, 3.0초 타이머, 성공/실패 컷
- `game.js` — 게임 로직·상사 상태 머신(페인트/커피 급복귀/스텔스/의심도), 시각 연출은 3D 씬에 위임
- `sfx.js` — Web Audio 효과음 + 프로시저럴 BGM(평온 105BPM ↔ 긴장 148BPM, 위장 시 로패스 덕킹, 탭 숨김 시 일시정지)

## CC0 실사 텍스처 (`textures/`)
Poly Haven CC0 텍스처 9세트를 512px WebP(diffuse/normal/roughness)로 경량화해(합계 약 680KB) 넣었다.
첫 프레임은 기존 단색·캔버스 재질 그대로 그리고, 파일이 도착하는 순간 `map`/`normalMap`/`roughnessMap`만 갈아 끼운다.

| 위치 | 텍스처 |
| --- | --- |
| 사무실 바닥 타일 | `interior_tiles` |
| 복도 카펫 | `dirty_carpet` |
| 책상 상판 | `kitchen_wood` |
| 벽면 | `painted_plaster_wall` |
| 파티션·차트 바닥·천장 | `concrete_floor_worn_001` |
| 점프 발판 잔디 / 흙 / 공중 블록 바위 | `aerial_grass_rock` / `stony_dirt_path` / `rock_surface` |
| 차트 배경·캐비닛·망치·카트 | `metal_plate` |

- 사진 디퓨즈는 원래 재질색의 평균 밝기·색조로 나눠 입혀 야간 사무실 무드를 유지하고, 글자·색이 의미를 갖는 면(초록 캔들 차트 바, 선물 박스, 사무실 문)은 노멀·거칠기만 보강한다.
- 로드 실패·지연 시에는 기존 재질이 그대로 남는다(폴백). `?notex`로 비교 모드. 출처는 `textures/CREDITS.md`.

## 최적화
- 두 렌더러 모두 `setPixelRatio(min(devicePixelRatio, 1.4))`, `PCFShadowMap`
- 위장(엑셀) 중에는 미니 3D 캔버스 렌더링 정지, 결과 화면에서는 두 씬 모두 정지
- 390×844 한 화면(`scrollHeight == 844`) 유지 · 타이틀은 월~금 5일 목록 + 상점 버튼까지 한 화면
